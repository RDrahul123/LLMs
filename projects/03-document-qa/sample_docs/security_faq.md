# Northstar Security FAQ

## Data and privacy

Northstar encrypts workspace traffic in transit using TLS. Customer data is encrypted at rest. Workspace owners can export their project data from Settings → Data export. Only workspace owners and administrators can manage member access.

## Authentication

Northstar supports email and password sign-in. Two-factor authentication is available in Personal settings → Security. Administrators can require two-factor authentication for all members of a workspace. Password reset links expire after 30 minutes.

## Data retention

When a workspace is deleted, its data is scheduled for permanent deletion within 30 days. Users can request an account data export by contacting privacy@northstar.example. Northstar does not use customer workspace content to train its public language models.
